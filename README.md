# IronLog Web

IronLog Web è una PWA: dopo la pubblicazione su un indirizzo HTTPS, aprila in Safari su iPhone, tocca Condividi e scegli **Aggiungi a Home**.

I dati restano sul dispositivo in IndexedDB e l'app funziona anche offline dopo la prima apertura. Usa **⚙ → Esporta backup** per salvare una copia dei dati; **Importa backup** la ripristina.

Per pubblicarla puoi caricare il contenuto di questa cartella su GitHub Pages, Netlify, Vercel o qualunque hosting HTTPS. Non richiede un database o un server per l'uso locale.
